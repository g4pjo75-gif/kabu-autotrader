# /write-plan → CCAGI Phase 2-3: Design + Planning

This command is redirected from a third-party plugin to CCAGI's workflow.

**Do not use a write-plan workflow.** Instead, execute CCAGI Phase 2-3:

```
/spec-create
/design-system
/create-ssot-issue
```

Phase 2 generates design documents, Phase 3 creates the SSOT Issue for tracking.

For conflict resolution between CCAGI commands and third-party plugins, run `ccagi-sdk doctor`.
